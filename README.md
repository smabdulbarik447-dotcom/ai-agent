# Shob Paabo AI — Facebook AI Agent SaaS (Next.js)

একটি প্ল্যাটফর্ম যেখানে যে কেউ অ্যাকাউন্ট খুলে, প্ল্যান কিনে, নিজের Facebook পেজে AI সেলস বট চালাতে পারে।

| লিংক | কে ব্যবহার করবে |
|---|---|
| `/` | পাবলিক ওয়েবসাইট — ফিচার ও প্রাইসিং |
| `/signup`, `/login` | ইউজার অ্যাকাউন্ট খোলা ও লগইন (শুধু ইউজার) |
| `/admin/login` | অ্যাডমিন লগইন (শুধু অ্যাডমিন) — এই লিংক ওয়েবসাইটে কোথাও দেখানো হয় না |
| `/dashboard` | ইউজারের প্যানেল — পেজ কানেক্ট, প্রোডাক্ট, অটো রিপ্লাই, ইনবক্স, অর্ডার, Billing |
| `/admin` | আপনার (সুপার অ্যাডমিন) প্যানেল — ইউজার, পেমেন্ট অনুমোদন, প্ল্যান, প্ল্যাটফর্ম সেটিংস |

## অনলাইনে লাইভ করা (Railway) — কম্পিউটার চালু রাখতে হবে না

1. github.com এ একটি **Private** repository বানান (যেমন `shobpaabo`), তারপর এই ফোল্ডারে cmd খুলে:
   ```bat
   git remote add origin https://github.com/<আপনার-username>/shobpaabo.git
   git push -u origin main
   ```
2. railway.com → **New Project → Deploy from GitHub repo** → repo টি বেছে নিন। Railway নিজেই `Dockerfile` দেখে বিল্ড করবে।
3. সার্ভিসে **Volume** যুক্ত করুন, Mount path: `/data` (ডাটা যেন রিডিপ্লয়ে না মোছে)।
4. **Variables** এ দিন: `ADMIN_EMAIL`, `ADMIN_PASSWORD` (নিজের শক্ত পাসওয়ার্ড)।
5. **Settings → Networking → Generate Domain** (বা নিজের ডোমেইন যুক্ত করুন) — https নিজে থেকেই চালু হবে।
6. `https://<ডোমেইন>/admin/login` এ ঢুকে Platform Settings পূরণ করুন। সেখানে **ব্যাকআপ ডাউনলোড** বাটনও আছে।

পরে কোড বদলালে শুধু `git add -A && git commit -m "update" && git push` — Railway নিজে নতুন ভার্সন লাইভ করবে, ডাটা থাকবে।

## নিজের কম্পিউটারে চালানো (টেস্টের জন্য)

ফোল্ডারের **`start.bat`** ফাইলে ডাবল-ক্লিক করুন → http://localhost:3000

- অ্যাডমিন লগইন: http://localhost:3000/admin/login → `admin@admin.com` / `admin123` — **`.env` ফাইলে প্রথমবার চালানোর আগেই বদলে নিন।**
- Node.js 22.13+ লাগবে। পোর্ট 3000 এ অন্য কিছু চালু থাকলে আগে বন্ধ করুন।
- কমান্ড দিয়ে: `npm install` → `npm run build` → `npm start` (cmd এ)

## AI যেভাবে শেখে

- **Facebook পেজ কানেক্ট করলে:** পেজের পোস্ট (লেখা + ছবি) পড়ে প্রোডাক্ট, দাম, অফার দাম নিজে তৈরি করে। অফার/ঠিকানার মতো অন্য তথ্য **AI Training** এ জমা হয়। নতুন পোস্ট নিয়মিত পড়ে।
- **ওয়েবসাইট সিঙ্ক করলে:** প্রোডাক্টের সাথে প্রতিটি ছবি দেখে বর্ণনা লিখে রাখে।
- **কাস্টমার ছবি/স্ক্রিনশট দিলে:** ছবি দেখে মিল থাকা প্রোডাক্ট খুঁজে নাম, দাম, অফার দাম, স্টক বলে, দরকার হলে প্রোডাক্টের ছবিও পাঠায়।
- **নিজে শেখানো:** Dashboard → **AI Training** এ এক ক্লিকের টেমপ্লেট, আর Inbox এ কাস্টমারের মেসেজের পাশে **✨ উত্তর শেখান**।
- পোস্ট ও ছবি পড়তে Claude API খরচ হয় (একবারই, প্রতিটি পোস্ট/ছবির জন্য)।

## প্রথমবার সেটআপ (অ্যাডমিন)

**Admin → Platform Settings** এ:

1. **পাবলিক URL** — আপনার ডোমেইন (যেমন `https://bot.yourdomain.com`)। Facebook এর জন্য https লাগবে।
2. **Claude API Key** — সব ইউজারের বট এটা দিয়ে চলবে। খরচ আপনার, প্ল্যানের AI রিপ্লাই লিমিট দিয়ে নিয়ন্ত্রিত।
3. **Facebook App** — একটি Meta App বানিয়ে App ID/Secret দিন। ধাপগুলো ওই পেজেই লেখা আছে।
   ইউজাররা যেন "Facebook দিয়ে কানেক্ট করুন" চাপলেই নিজের পেজ যুক্ত করতে পারে, তার জন্য Meta তে
   `pages_messaging`, `pages_manage_metadata`, `pages_show_list` পারমিশনের **App Review** লাগবে।
   রিভিউ পাওয়ার আগে শুধু App এ Tester হিসেবে যোগ করা অ্যাকাউন্টই কানেক্ট করতে পারবে।
4. **পেমেন্ট নম্বর** — বিকাশ/নগদ/রকেট (Send Money)।
5. **ফ্রি ট্রায়াল** — নতুন অ্যাকাউন্টে কত দিন, কোন প্ল্যান (ডিফল্ট: ৩ দিন Starter)।

**Admin → Plans** এ Starter / Business / Pro এর দাম ও লিমিট বদলাতে পারবেন, নতুন প্ল্যানও বানাতে পারবেন।

## ইউজারের যাত্রা

1. ওয়েবসাইট থেকে সাইন আপ → অটোমেটিক ফ্রি ট্রায়াল চালু
2. **Billing** → প্ল্যান বেছে নিয়ে বিকাশ/নগদে Send Money → TrxID জমা
3. আপনি **Admin → Payments** এ নিজের বিকাশ অ্যাপে TrxID মিলিয়ে **অনুমোদন** দেন → প্ল্যান সাথে সাথে চালু (একই প্ল্যান হলে মেয়াদ বাড়ে)
4. ইউজার **Facebook Pages** থেকে পেজ কানেক্ট করে, **Products** এ ওয়েবসাইট সিঙ্ক করে, **Auto Reply** রুল বানায় — বট চালু

প্ল্যানের মেয়াদ শেষ হলে বট উত্তর দেওয়া বন্ধ করে। AI লিমিট শেষ হলে শুধু অটো রুল ও ডিফল্ট রিপ্লাই চলে।
**Admin → Users** থেকে যেকোনো ইউজারকে হাতে প্ল্যান দিতে, প্ল্যান বন্ধ করতে বা অ্যাকাউন্ট সাসপেন্ড করতে পারবেন।

## হোস্টিং

২৪ ঘণ্টা চালাতে VPS বা Railway/Render এর মতো হোস্টিং লাগবে যেখানে ফাইল থাকে (ডাটা থাকে `data/app.db` এ)।
Vercel এর মতো serverless এ চলবে না। লোকাল টেস্টের জন্য: `npx cloudflared tunnel --url http://localhost:3000`

## ফোল্ডার

```
app/page.js           পাবলিক ল্যান্ডিং পেজ
```
